# SMK Mobiles & Photography

SMK Mobiles & Photography is a premium, dark-themed e-commerce website for mobile sales, service, accessories, repairs, and photography studio offerings. The project uses Flask with JSON-based product storage and a polished responsive UI.

## Features
- Modern dark luxury UI with glassmorphism and premium animations
- Responsive storefront with dedicated pages for home, about, products, services, brands, gallery, offers, testimonials, FAQ, and contact
- Product catalog with search and brand filtering
- Admin panel with login, dashboard, product add/edit/delete, and image upload support
- JSON file storage only (no database required)

## Run Locally
```bash
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000
